# BJ-23: The daily reminder on the phone

## Brief

<!-- Gate 1. Small: what, why, done-when, and the test that should fail first. Full: see gw-brief. -->
A daily reminder at a time the reader picks, as local notifications scheduled on the phone (no server sender, no change to profiles.reminder_time, which the web-push sender reads). Settings gets the Daily reminder group; permission is asked only when it is turned on. The next 7 days are kept scheduled with the reading of her current day, today's skipped once she has read today, rescheduled on progress, time and foreground changes. Stacked on gw/BJ-22 (PR #29).
